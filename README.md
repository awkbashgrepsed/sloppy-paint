# Sloppy Paint

A small Rust/egui paint program.

## V2 features

- Pencil
- Eraser
- Color picker
- Bucket/flood fill
- Line tool
- Rectangle tool
- Ellipse tool
- Brush size control
- Color palette
- Resizable canvas using the bottom-right drag handle
- Canvas dimensions shown in the toolbar
- PNG open/save
- New canvas

## Run

```bash
cargo run
```

## Release build

```bash
cargo build --release
```
